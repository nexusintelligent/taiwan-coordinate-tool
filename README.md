# 智聯 GeoDesk｜工程座標與圖資工作台

由智聯工程科技顧問有限公司製作與維護。

一套離線優先的 PWA 網頁工具，用於從混合文字中擷取座標、轉換 WGS84 與 TWD97，並在連線時使用國土測繪圖資服務雲確認位置。

## v0.3 輕量圖資編輯

- 依近期 QGIS 工程及生態檢核專案整理的公司圖徵預設
- 智聯工程點位、工程線位、工程範圍、生態調查範圍、1 km 影響範圍、TBN 點位及其他單位案件
- 點、線、面繪製，節點修改與圖徵吸附
- 圖徵名稱、備註、樣式與工作圖層清單
- 自動計算線長及面積
- GeoJSON 匯入與匯出，方便與 QGIS 交換資料
- 座標轉換與圖資編輯分頁，地圖維持同步檢核

## 目前功能

- WGS84（EPSG:4326）與 TWD97 / TM2 zone 121（EPSG:3826）雙向轉換
- 自動判斷 `緯度, 經度`、`經度, 緯度` 與 `X, Y`
- 從含有中文說明、括號與編號的文字擷取多組座標
- 臺灣範圍合理性檢查與明確錯誤訊息
- 自訂 XY、經緯度小數位與進位方式
- 內建及自訂輸出格式
- 一鍵複製結果
- 國土測繪圖資服務雲臺灣通用電子地圖、正射影像
- 可安裝 PWA；斷網時保留轉換、解析和格式化功能
- 原文座標替換、Excel 表格複製與逐列快速複製
- 點位提示、標籤、連線開關與游標即時座標

## 線上與離線邊界

座標及輸入文字都在瀏覽器本機處理，不會送到伺服器。國土測繪中心 WMTS 底圖只在連線時載入，且不進行大量或離線快取。

